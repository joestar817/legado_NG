## 硅基流动使用帮助

### 提供商介绍

硅基流动提供多家厂商的模型推理服务。NG 预设接入硅基流动中国站。

### 提供哪些模型

- **DeepSeek、Qwen、GLM 等系列**。覆盖文本对话和推理。
- **图像、语音和向量模型**。可在模型广场按用途查看。

**部分模型有免费版。** 同一型号同时提供免费版和付费版时，付费版的模型 ID 以 `Pro/` 开头。各型号的价格和限额可在模型广场查看。

[模型目录](https://www.siliconflow.cn/models) · [免费版说明](https://api-docs.siliconflow.cn/docs/userguide/faqs/misc)

### 在哪里注册和获取 API Key

1. 注册或登录硅基流动中国站。[打开控制台](https://cloud.siliconflow.cn/)
2. 在「API 密钥」页面创建并复制 API Key。[获取 API Key](https://cloud.siliconflow.cn/account/ak)

### 怎么在 NG 中使用

1. 把密钥粘贴到「API Key」，使用预填的 API 地址和路径。
2. 打开「启用 AI」，点击「测试连通性」，确认能读取模型列表。
3. 切到下方「模型」页，下拉刷新并启用文本对话模型。
4. 在「AI 设置 → AI助理 → 聊天模型」选择已启用的模型。
