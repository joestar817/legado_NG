## Exa 搜索服务帮助

### 提供商介绍

Exa 支持按问题含义查找网页。NG 使用 **Auto** 搜索获取链接和相关片段，通过 **Contents** 读取指定链接的正文。

### 费用和免费额度

- **每月 10 美元的免费 API 额度**，每月 1 日刷新，无需绑定信用卡。
- Auto 搜索每次最多返回 10 条时为 **7 美元／1,000 次请求**，超过 10 条的部分为 **1 美元／1,000 条结果**。
- 用 Contents 抓取网页正文为 **1 美元／1,000 页**。

[Exa 定价与免费额度](https://exa.ai/pricing)

### 在哪里注册和获取 API Key

1. 注册或登录 [Exa 控制台](https://dashboard.exa.ai/)。
2. 在 [API Keys](https://dashboard.exa.ai/api-keys) 创建并复制密钥。

### 怎么在 NG 中使用

1. 把密钥粘贴到「API Key」，打开「启用服务」。
2. 在「测试服务」选「网页搜索」输入关键字，或选「网页抓取」粘贴链接，点箭头查看结果。
3. 在「AI 设置 → AI助理」将「联网方式」设为「指定外置服务」，并在「外置搜索服务」选 Exa。选择支持工具调用的聊天模型，打开输入框的联网开关。
