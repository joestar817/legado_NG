## Codex 使用帮助

### 登录并选择模型

阅读 NG 可以用你的 ChatGPT 账号连接 Codex，在 AI 助理里聊天、生图和改图。

1. 打开「AI 设置 → 提供商 → Codex」，点击「登录 Codex」。在浏览器完成授权后返回 NG。可以在同一页添加或切换账号。
2. 打开「启用 AI」，切到底部「模型」页并启用想用的聊天模型。列表为空时，可以在该页刷新。
3. 在「AI 设置 → AI助理 → 聊天模型」选择 Codex 下的模型，也可以在聊天中切换模型。

### 在聊天中生图或改图

- 直接在聊天里描述要画的内容，例如「画一张雨天书店的插图」。想明确发起生图时，点输入栏的「＋ → 生图」，再输入描述。
- 想修改已有图片时，从「＋」里的「照片」「拍照」或「作品」添加参考图，再描述改动。也可以对生成过的图片选择「更多 → 继续改图」，把原图带回输入栏。
- 点成图可以全屏查看。图片的「更多」菜单和全屏预览顶部都能继续改图、下载或分享。

看不到输入栏的「＋」时，先确认当前聊天模型来自 Codex，再检查 Codex 提供商是否已登录并启用。

### 管理作品

生成的图片会出现在「＋ → 作品」里。打开「管理作品」，可以多选并保存到系统相册，或选择「从作品列表移除」。在「已移除」里可以批量恢复。移除只影响作品列表，原图依然能从聊天记录打开。

### 查看套餐用量

Codex 提供商页的「套餐概览」会显示账号返回的当前套餐、各周期的剩余百分比与重置时间，以及可用额度。点刷新图标可以查看最新用量。如果提示「授权已失效」，回到此页点「重新授权」。
