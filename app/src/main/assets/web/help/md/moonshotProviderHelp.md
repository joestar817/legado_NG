## 月之暗面使用帮助

### 提供商介绍

Kimi API 开放平台由月之暗面运营，提供可用于阅读问答、长文摘要和内容分析的 Kimi 模型。

### 提供哪些模型

- **Kimi K3**（`kimi-k3`）。适合日常对话和长文本处理。
- **Kimi K3.1 Pro**（`kimi-k3.1-pro`）。适合复杂分析和推理任务。

**按用量计费。** 输入、输出及缓存适用各自的价格。

[模型与计费](https://platform.kimi.com/docs/pricing/chat)

### 在哪里注册和获取 API Key

1. 注册或登录 Kimi API 开放平台。[打开控制台](https://platform.kimi.com/)
2. 在开放平台的 API Keys 页面创建并复制 API Key。[获取 API Key](https://platform.kimi.com/console/api-keys)

### 怎么在 NG 中使用

1. 把密钥粘贴到「API Key」，使用预填的 API 地址和路径。
2. 打开「启用 AI」，点击「测试连通性」，确认能读取模型列表。
3. 切到下方「模型」页，下拉刷新并启用文本对话模型。
4. 在「AI 设置 → AI助理 → 聊天模型」选择已启用的模型。
