## OpenRouter 使用帮助

### 提供商介绍

OpenRouter 通过统一的 API 提供多家厂商的模型。一个 API Key 可在平台可用的对话模型之间切换。

### 提供哪些模型

- **GPT、Claude、Gemini 等系列**。提供文本对话、推理和多模态型号。
- **DeepSeek、Qwen、Kimi 等系列**。可在模型目录按能力、输入类型和价格筛选。

**部分模型有免费版。** ID 以 `:free` 结尾的版本可免费调用，受次数、速率和可用性限制。在 NG 的「模型」页搜索 `:free` 可筛出这些版本。

[模型目录](https://openrouter.ai/models) · [免费模型](https://openrouter.ai/collections/free-models/)

### 在哪里注册和获取 API Key

1. 注册或登录 OpenRouter。[打开控制台](https://openrouter.ai/)
2. 在 Keys 页面创建并复制 API Key。使用付费模型前可在账户中添加额度。[获取 API Key](https://openrouter.ai/keys)

### 怎么在 NG 中使用

1. 把密钥粘贴到「API Key」，使用预填的 API 地址和路径。
2. 打开「启用 AI」，点击「测试连通性」，确认能读取模型列表。
3. 切到下方「模型」页，下拉刷新并启用文本对话模型。
4. 在「AI 设置 → AI助理 → 聊天模型」选择已启用的模型。
