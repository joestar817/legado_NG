## 智谱使用帮助

### 提供商介绍

智谱开放平台提供 GLM 系列的模型服务。NG 预设使用模型标准 API。

### 提供哪些模型

- **GLM-5.3 等通用模型**。适合复杂文本分析和推理。
- **GLM-5.3-Flash、FlashX 等模型**。提供图文理解和文本推理能力。

**部分对话模型免费。** 官方价格页把 `glm-4.7-flash` 的文本输入和输出标为免费，实际可用型号以账号的模型列表为准。

[模型目录](https://docs.bigmodel.cn/cn/guide/start/model-overview) · [计费说明](https://docs.bigmodel.cn/cn/guide/start/pricing)

### 在哪里注册和获取 API Key

1. 注册或登录智谱开放平台。[打开控制台](https://open.bigmodel.cn/)
2. 在 API Keys 页面创建并复制「模型标准 API」的 API Key。[获取 API Key](https://bigmodel.cn/usercenter/proj-mgmt/apikeys)

### 怎么在 NG 中使用

1. 把密钥粘贴到「API Key」，使用预填的 API 地址和路径。
2. 打开「启用 AI」，点击「测试连通性」，确认能读取模型列表。
3. 切到下方「模型」页，下拉刷新并启用文本对话模型。
4. 在「AI 设置 → AI助理 → 聊天模型」选择已启用的模型。
