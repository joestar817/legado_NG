## TinyFish 搜索服务帮助

### 提供商介绍

TinyFish 的 **TinySearch** 返回网页检索结果，**TinyFetch** 按链接提取正文。NG 搜索中文关键字时会指定中国地区和中文语言。

### 费用和免费额度

- **TinySearch 每日 12,000 次免费搜索**，**TinyFetch 每日可免费抓取 1,000 个网址**，抓取仅计成功的网址。每日额度在北京时间 08:00 重置。
- 免费额度无需绑定信用卡。用完后可以等额度重置，也可以在 TinyFish 钱包查看超额使用选项和费用。

[TinySearch 额度](https://docs.tinyfish.ai/tinysearch/reference#billing) · [TinyFetch 额度](https://docs.tinyfish.ai/tinyfetch/reference#billing) · [定价说明](https://www.tinyfish.ai/pricing)

### 在哪里注册和获取 API Key

1. 注册或登录 [TinyFish 控制台](https://agent.tinyfish.ai/)。
2. 在 [API Keys](https://agent.tinyfish.ai/api-keys) 创建并复制密钥。

### 怎么在 NG 中使用

1. 把密钥粘贴到「API Key」，打开「启用服务」。
2. 在「测试服务」选「网页搜索」输入关键字，或选「网页抓取」粘贴链接，点箭头查看结果。
3. 在「AI 设置 → AI助理」将「联网方式」设为「指定外置服务」，并在「外置搜索服务」选 TinyFish。选择支持工具调用的聊天模型，打开输入框的联网开关。
