## Agnes AI 使用帮助

### 提供商介绍

NG 预设接入 Agnes AI 国际站。填写 API Key 后，可刷新账号的模型目录。

### 提供哪些模型

- **Agnes 3.0 Flash** 适合日常聊天，支持流式回复和工具调用。
- **Agnes Pro 系列** 按所选型号计费。

默认用户目前可按 $0 体验价使用 Agnes 3.0 Flash。实际价格和限流以账号控制台为准。建议选择 `agnes-3.0-flash`，上一代 `agnes-2.5-flash` 计划于 2026 年 11 月 30 日下线。

[模型与定价](https://wiki.agnes-ai.com/zh-Hans/docs/pricing) · [订阅与限流](https://wiki.agnes-ai.com/zh-Hans/docs/tokenplan)

### 获取 API Key

登录国际站控制台，在 API Key 管理中创建并复制密钥。[打开控制台](https://platform.agnes-ai.com/)

### 在 NG 中使用

1. 在「配置」页粘贴 API Key，使用预填的地址，点击「测试连通性」。
2. 在「模型」页下拉刷新并启用 `agnes-3.0-flash`。
3. 在 AI 助理中选择该模型开始聊天。
