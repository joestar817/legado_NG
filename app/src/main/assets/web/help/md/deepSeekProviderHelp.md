## DeepSeek 使用帮助

### 提供商介绍

DeepSeek 开放平台由深度求索运营，提供对话和推理模型，可用于阅读问答、摘要和文本分析。

### 提供哪些模型

- **DeepSeek V4.1 Flash**（`deepseek-flash`）。适合日常问答、摘要和阅读辅助。
- **DeepSeek V4 Pro**（`deepseek-v4-pro`）。适合复杂问题分析和推理。

**按用量计费。** 账户有赠送余额时优先抵扣，可在开放平台查看余额。

[模型与计费](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

### 在哪里注册和获取 API Key

1. 注册或登录 DeepSeek 开放平台。[打开控制台](https://platform.deepseek.com/)
2. 在 API Keys 页面创建并复制 API Key。[获取 API Key](https://platform.deepseek.com/api_keys)

### 怎么在 NG 中使用

1. 把密钥粘贴到「API Key」，使用预填的 API 地址和路径。
2. 打开「启用 AI」，点击「测试连通性」，确认能读取模型列表。
3. 切到下方「模型」页，下拉刷新并启用文本对话模型。
4. 在「AI 设置 → AI助理 → 聊天模型」选择已启用的模型。
