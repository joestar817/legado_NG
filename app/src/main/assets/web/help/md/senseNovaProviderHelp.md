## 商汤使用帮助

### 提供商介绍

SenseNova 日日新是商汤的大模型平台。NG 预设接入中国内地的 Token Plan 服务。

### 提供哪些模型

- **SenseNova 6.8 Flash Lite**。适合日常文本处理和推理。
- **SenseNova U1 Fast**。面向图文等多模态任务。

**公测提供免费额度。** 当前可用模型、领取条件和剩余额度可在 Token Plan 控制台查看。

[模型与计费](https://www.sensenova.cn/token-plan)

### 在哪里注册和获取 API Key

1. 注册或登录日日新控制台，按提示完成实名认证并开通 Token Plan。[打开控制台](https://platform.sensenova.cn/token-plan)
2. 在 API Key 管理页面创建并复制 Token Plan 使用的 API Key。[获取 API Key](https://platform.sensenova.cn/console/keys)

### 怎么在 NG 中使用

1. 把密钥粘贴到「API Key」，使用预填的 API 地址和路径。
2. 打开「启用 AI」，点击「测试连通性」，确认能读取模型列表。
3. 切到下方「模型」页，下拉刷新并启用文本对话模型。
4. 在「AI 设置 → AI助理 → 聊天模型」选择已启用的模型。
