## 火山引擎使用帮助

### 提供商介绍

火山方舟是火山引擎的大模型服务平台。NG 预设通过方舟接入豆包和其他厂商的模型。

### 提供哪些模型

- **豆包（Doubao）系列**。提供文本对话、推理和视觉理解型号。
- **第三方模型和生成模型**。可在方舟模型广场查看，包括图像和视频生成型号。

**新用户有免费推理额度。** 各模型的额度和开通状态可在控制台查看。试用结束后，可开通所用模型继续付费调用。

[模型与计费](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh) · [试用额度](https://docs.volcengine.com/docs/ark/free-inference-quota?lang=zh)

### 在哪里注册和获取 API Key

1. 注册或登录火山引擎，进入火山方舟并切换到要使用的项目。[打开控制台](https://ark.volcengine.com/region:cn-beijing/openManagement)
2. 在「API Key 管理」页面创建并复制 API Key。[获取 API Key](https://ark.volcengine.com/region:cn-beijing/apiKey)

### 怎么在 NG 中使用

1. 把密钥粘贴到「API Key」，使用预填的 API 地址和路径。
2. 打开「启用 AI」，点击「测试连通性」，确认能读取模型列表。
3. 切到下方「模型」页，下拉刷新并启用文本对话模型。
4. 在「AI 设置 → AI助理 → 聊天模型」选择已启用的模型。
