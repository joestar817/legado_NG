## WorkBuddy 使用帮助

### 登录并选择模型

阅读 NG 可以直接用国内版 WorkBuddy 账号进行文字对话。

1. 打开「AI 设置 → 提供商 → WorkBuddy」，点击「登录 WorkBuddy」。在浏览器完成登录后返回 NG，等待账号卡显示当前账号。
2. 打开「启用 AI」，切到底部「模型」页并启用想用的模型。列表为空时，可以在该页刷新。
3. 在「AI 设置 → AI助理 → 聊天模型」选择 WorkBuddy 下的模型。回复会边生成边显示，可以在同一聊天里继续追问。

### 看懂模型列表

模型管理和聊天的模型选择抽屉都会展示账号返回的上下文窗口和积分倍率。上下文窗口表示模型一次能处理的内容上限。同名模型可以通过旁边的倍率区分，服务返回 `0.00×` 时也会显示。模型和倍率以当前账号目录为准。

### 查看积分和领取奖励

- 登录个人账号后，账号卡会自动显示「积分余额」和「Buddy 加油站」的领取状态。余额旁的刷新图标可以同时刷新两项信息。
- 加油站显示「领取积分」时，点击领取当天奖励。领取成功后，NG 会更新领取状态并重查余额。显示「今日已领」时，当天的奖励已领取。

### 登录失效怎么办

NG 会在使用时自动续期。若提示「授权已失效」，回到 WorkBuddy 提供商页点击「重新授权」，在浏览器完成登录后返回 NG。账号卡底部可以退出登录。
