# 背景音乐播放列表图标

- 图标：[Lucide list-music（Iconify）](https://icon-sets.iconify.design/lucide/list-music/)。
- 原始 SVG：[lucide-icons/lucide/icons/list-music.svg](https://github.com/lucide-icons/lucide/blob/main/icons/list-music.svg)。
- 作者：Lucide Icons and Contributors；许可证为 ISC，完整许可文本已随应用打包在 `app/src/main/assets/licenses/lucide-manga-icons.txt`。
- 本地资源：`app/src/main/res/drawable/ic_bgm_playlist.xml`。

将原始路径和圆转换为 Android VectorDrawable，保留 24×24 视口、2 单位圆端描边；听书抽屉以 20dp 图标槽显示，颜色沿用当前主题及选中状态。不引入运行时图标下载或依赖。
