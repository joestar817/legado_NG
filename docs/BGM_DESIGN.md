# 听书背景音乐

## 歌曲VIP标识（2026-10-23）

QQ/网易搜索结果、歌单详情及听书抽屉共用歌曲行，在歌手旁显示紧凑VIP标签：QQ绿色浅底、网易红色细边，暗色主题使用相应高亮文字。长歌手名称优先省略，保留标签；行高、封面、时长、试听和菜单位置保持。

`MusicTrack.isVip`为可空目录元数据，稳定序列化名为`isVip`。只有平台明确标记时显示，缺字段为未知；本地文件不显示。QQ以播放付费且绿钻/付费包两个明确标志为准，网易只认fee=1。该字段不改变试听、完整播放、队列权限或当前账号权益，不新增网络请求，也不隐式回填旧保存队列；来源与样本见BGM_PROTOCOL_SOURCES.md。

## 试听进度与独立音量（2026-10-23）

用户选择第二张视觉稿：104dp紧凑试听条，曲目/暂停/关闭在上行，进度与音量入口在下行；点音量入口打开其上方的锚点浮层。浮层只控制试听会话的音量，初始化时读取一次当前配乐音量，随后调节/静音均不写正式BGM设置；关闭浮层不停止试听。全屏曲库及本地导入预留120dp，听书抽屉试听时临时替换正式配乐dock，结束后恢复。

试听进度独立发布，播放时每250ms更新叶子组件，暂停/换曲/关闭取消旧任务；拖动携曲目key，只在当前READY且可定位的媒体上执行，暂停中定位不自动续播。进度使用实际媒体时长，未知时长禁用。官方独立片段用较大点表示本次文件播放经过时间、较小固定点表示本次文件可播长度，整体长度以整曲时长作参照；不声称片段在原曲中的精确起点，不使用未经核实的try_begin/end偏移或裁剪。到末尾沿原试听结束/配乐恢复语义处理。

QQ试听先补同MID详情获取media_mid/type，再请求普通M500；仅其返回104003或无有效路径，且详情明确提供vs[0]与正数size_try时，请求官方RS02独立片段。缺失CDN时使用正常GetCdnDispatch。正式BGM继续拒绝片段，不把短试听加入完整播放；网易原有片段限制本轮保持。该接入以2026-10-23独立微信账号测试的真实RS02结果为依据，Android运行结果仍按本轮安装/设备检查记录。

## 用户目标

在手机上直接登录音乐平台，管理在线和本地曲库；在线歌单的修改直接同步网易云／QQ 音乐账号。听书播放界面消费曲库，负责选择本次配乐、队列与播放控制。

2026-10-20 用户纠正定位：本页做曲库 CRUD，不能围绕“选择内容设为背景音乐”组织。2026-10-21 已按确认稿接入曲库／歌单双页与管理动作，平台真实写入尚待验收，能力范围见下文。原三页设计稿中的当前配乐卡和选曲底栏已不再作为管理页基线。

本轮 UI 调整：删除固定当前配乐卡；试听时在页内底部显示短浮条，可停止且给列表留出空间；平台／本地搜索并入悬浮顶栏；歌单和歌曲采用连续紧凑列表。账号与登录统一为 NG 弹窗；网易云保留手机号验证码／扫码，QQ 提供手机登录、微信扫码、QQ 扫码三个明确入口。全局设置进入管理模式，听书播放页进入独立“选择配乐”模式，只有后者允许提交播放列表。上述为代码接入，不等于实机视觉、短信或授权已经验收。

连续歌单／歌曲列表的整体首尾使用 NG 表单圆角，中间行保持平直、无卡片间距；歌曲只有一项时四角均圆。全局朗读设置的“背景音乐”入口使用音符图标，与本地音乐保持一致。

在线歌曲列表按确认稿采用左侧专辑封面、歌曲／歌手双行、独立时长和右侧试听／更多菜单；搜索结果按已提交的关键词高亮，当前试听行轻微着色。封面读取每首歌曲已有的 `coverUrl`，空图／加载失败使用音符占位；批量管理沿用勾选动作。在线歌曲行支持开始、暂停、继续试听，加载中可取消，底部浮条保留停止入口。加入／移出歌单仍走原有选择与确认流程。在线根页搜索默认折叠为标题栏；展开后仅保留关键词清空按钮，左侧返回先清空并收起搜索。实际封面加载、交互和视觉仍待安装后验收。

登录区域按用户确认的整合稿实现：未登录时使用一张紧凑卡片，包含平台原色图标、“我的歌单”、同步提示与实底登录按钮。登录弹窗采用平台图标标题、右上关闭、文字下划线 Tab、小标签与细线输入、底部全宽主按钮；扫码方式使用紧凑二维码、状态与刷新操作。网易云和 QQ 共用结构并保留各自品牌和扫码说明。国家码保留原可编辑数字输入，显示 `+` 前缀；验证码冷却、验证挑战、取消和账号存储仍由原 ViewModel／Provider 负责。设计确认不代替安装后的实际视觉和键盘状态验收。

网易云已登录弹窗改为资料卡：平台图标标题与关闭、72dp 圆形头像、居中昵称、已登录／等级标签和可选签名，浅分隔线下展示关注、粉丝、听歌数，底部全宽描边退出按钮继续使用原确认流程。资料仅在打开弹窗时读取，关闭／切换平台／退出时取消，并校验账号与请求代次；统计接口失败保留账号接口已返回的基础资料，显示重试。缺失计数不当成零，空签名隐藏；`listenSongs` 只表示听歌数，不换算小时。QQ 已接同样资料卡：同批核对登录态、主页／音乐基因卡片的账号身份，展示头像、昵称、签名、关注和粉丝；不使用截图中的数字，不添加未接入的勋章、访客或搭子占位。代码与真实账号／实机视觉验收分开记录。

等级信息在基础资料已显示后单独读取，最多等待8秒。会员使用接口原版静态徽标，与账号等级并排；图片高20dp、宽42–100dp并保留比例，缺图／加载失败时显示真实等级文字。账号资料卡不再放“已登录”占位，缺失／异常响应不当成非会员，保留资料并提供重试。只有接口明确给出未生效状态时将历史VIP徽标灰显，未提供有效性的平台不自行推断；读取沿用同一请求代次、账号epoch与关闭取消逻辑，不落盘，不增加会员权益操作。

## 页面职责

1. 全局“朗读设置→背景音乐”保留为管理入口。首页只展示网易云、QQ 音乐、本地音乐，附真实账号状态或本地数量／占用；保留已落实的品牌图标与 NG 卡片视觉。
2. 管理首页移除“当前配乐”、音量、下一首、当前播放列表。这些属于听书播放界面；删除管理页总开关之后，不再用另一组播放控件替代它。
3. 在线平台页提供搜索、我的歌单、收藏歌单及账号入口；新建歌单是管理动作。账号状态不能替代歌单所有权／写权限判断。
4. 歌单详情以浏览和管理为默认状态。歌曲默认不带常驻勾选框；长按或菜单进入批量管理，勾选仅服务于加入歌单、从歌单移除等明确动作。移除“设为背景音乐”“加入当前列表”“整张歌单设为背景音乐”等播放提交入口。
5. 本地页提供添加、搜索、排序、编辑条目信息、移除及批量管理。编辑显示信息作用于 NG 条目，不擅自改写用户原始音频标签。
6. 可保留歌曲试听作为识别内容的辅助功能，试听不创建配乐任务，也不改变持久播放列表。打开曲库、歌单或返回页面都不自动播放。
7. 听书播放页单独负责本次配乐选择、启停、音量、下一首、播放模式和当前队列；所用曲目引用同一曲库／平台身份，不另建一份曲库。具体播放面板布局另行细化，不借本轮管理调整重排播放器。

“加入歌单”使用底部抽屉：固定标题、顶部拖拽提示线，不设关闭按钮，通过下拉、返回或点击遮罩关闭。下方“新建歌单”、歌单、加载／空态／错误及分页内容共用一整块连续白底，只在整体首尾保留圆角。新建首项使用加号方块，其余显示平台真实封面、名称和歌曲数，空封面使用音符占位。内容外侧16dp，白底与书架操作抽屉共用 NG 内容卡颜色，歌单不拆成独立卡片。列表直接消费已有可编辑歌单及分页结果，点选仍同步到平台，提交中禁用重复操作及关闭；新建／编辑／删除确认保持现有弹窗流程。抽屉材质、圆角和边距复用 NG 全局抽屉配置，未扩大平台写能力。

## 在线曲库与歌单 CRUD

网易云／QQ曲库搜索和歌单详情使用SVG Spinners的`3-dots-fade`三点渐隐加载动画，颜色跟随NG主题。首屏／刷新显示在白色内容区（歌单详情位于封面信息下方），追加分页显示在列表尾部；这两个歌曲列表场景不再显示上层悬浮刷新圆盘或重复“加载中”文字，原下拉刷新手势保留。歌单根列表等其它页面的加载行为不变。动画使用本地Compose绘制，墨水屏静态显示，来源与许可见[加载动画说明](licenses/BGM_LOADING_ANIMATION.md)。

空歌单详情复用曲库空态的浅色阴刻平台图标和居中文字，文案保留“歌单里还没有歌曲”；80dp图标、4dp图文间距、13sp文字／18sp行高和整体白底圆角沿用现有组件。仅在原有加载结束、无错误且歌曲为空的分支显示，封面信息和添加入口不变；搜索前提示、添加引导、搜索无结果及错误重试保持原样。

用户已明确选择“直接同步平台账号的歌单”，不以 NG 内歌单副本代替平台写操作。下面是目标操作，须按实际平台能力实现。

歌单根列表的“新建”和详情“添加歌曲”使用NG文字按钮TEXT外观：无底色／描边，主题色14sp文字、20sp行高，40dp操作高度与8dp水平内边距，不附加固定最小宽度。现有加号矢量使用20sp对应的尺寸并随字体缩放，使实际绘制字高接近14sp文字；图文间距4dp、垂直居中，图标继承文字颜色与禁用透明度。保留原48dp／44dp标题行、列表14dp边距和按钮位置。

删除歌单、移出歌曲、取消收藏三种确认统一使用NG紧凑确认外壳：18sp居中半粗标题，浅色信息区内显示48dp封面、两行以内的歌单名与12sp数量；移出显示本次“已选N首”，删除／取消收藏显示歌单歌曲数。去掉“将从平台账号删除”“将同步到平台账号”等重复小字提示；信息区采用主题中圆角、10dp内边距、12dp图文间距。底部等宽按钮高44dp，取消为中性色，删除／移出用红色与空心垃圾桶，取消收藏用主题色与空心星标。提交中禁用操作／误关保护、真实错误反馈、权限与原平台回调保持；新建／编辑下划线表单、歌单选择抽屉和其它账号／本地确认不在本轮重排。

## 本地曲库 CRUD

本地音乐通过独立“添加本地音乐”页选择目录、浏览或扫描子目录、勾选试听和批量添加；目录来源默认引用原文件，持久保存明确的来源 URI／根目录／文件信息／摘要，`localPath`仍只表示NG私有副本。菜单另保留“导入文件副本”，副本仍有512MB单文件限制；引用式添加不复制整份音频。批量操作覆盖全部已选项，按进度可停止，完成后分别汇总新增、重复、失败和未处理数量，失败可重试。

移除只删除 NG 条目及NG拥有的副本，外部引用的原文件永不删除；队列同步移除对应条目。文件移动／权限失效时提示重新定位／授权，歌曲菜单提供重新定位入口，替换来源保持原歌曲ID并更新队列引用。条目信息编辑仍为独立待办，不在本轮增加或改写用户音频标签。

目录页复用本地书籍42dp路径栏、紧凑选择框和52dp底栏，单一亮白面板；扫描支持逐批结果、停止、搜索、名称／歌手／时长／大小／修改时间排序，以及录音、隐藏文件和最小时长筛选。短音频默认保留。来源URI已存在的歌曲显示“已添加”；未知／失败元数据不伪造，编码不支持的行显示原因。根目录切换前提醒清空选择，同根目录下导航、搜索和排序按稳定URI保留选择。顶栏田字菜单右侧展开，条目菜单维持锚点展开。

扫描枚举串行、元数据全局最多八个并发任务（系统媒体解析仍限四个）、屏幕内歌曲优先读取，标签和封面在同一次打开中处理。带完整且不超过512KiB的ID3v2标签、可读取声明时长的MP3复用已有Media3解析器校验实际MPEG帧、标签、封面与时长，并检查设备解码器；标签不完整、超出探测上限或其它容器仍走系统媒体解析。单次文件属性查询读取名称／大小／修改时间／类型，系统解析时检查编码和读取标签复用同一文件描述符。成功的读取结果按文件身份、名称、大小和修改时间缓存在最多512项的内存LRU中，扫描与添加共享；版本未知时不复用，文件变化后重新检查，失败不缓存。读取任务每批按新候选重新补足，并在后台自行领取；结果通过有界队列交回页面，避免首批稀疏时退回单路读取及逐首等待主线程。UI按批次节流更新并在后台排序；离开页面和更换扫描范围取消旧任务。引用添加最多并行准备四首（属性复查、格式检查、SHA-256与读后版本检查），按勾选顺序消费结果和判重，每20项持久化一批；停止取消未消费的预读任务，保留已处理项。同名不同内容不合并。试听复用现有控制器且不偷偷入库，新增曲库条目不替换播放队列。

本地曲库列表参照在线曲库，整体白色内容在视口边界统一裁切圆角，长列表底部留出间距，少量结果自然收口。非空列表卡片顶部使用48dp标题行：左侧“本地音乐”、右侧歌曲数量，去掉该行重复的添加按钮；顶栏更多菜单保留添加入口。此顶栏SIDE_SLIDE菜单显式允许窗口越过屏幕边界，并接收返回键，与书源管理一致；行内菜单仍沿用原锚点弹出。本地与在线歌曲管理、添加歌曲、选择配乐统一52dp底栏，按书源管理的分隔操作轨显示已选数、图标全选／反选／更多；零选择仍显示底栏，更多内提交动作禁用。原加入／移出歌单、移出曲库、设为背景音乐及加入当前列表收进更多，完成管理保留顶栏。目录导入已有全选／反选和直接添加／定位，保留其任务型按钮。首页大小代表私有音乐副本与曲库内外部引用文件的合计；外部部分使用最近入库／重新定位时记录的文件大小，并按文件身份去重，不把该数值称为应用私有存储占用。曲库增删后及时刷新统计。

本地曲库行内的试听按钮与在线曲库一致：播放中点按暂停、暂停后点按继续，加载中点按停止；关闭试听仍由试听条负责，复用现有试听控制器和音频焦点行为。

发现范围为MP3、AAC／M4A、FLAC、PCM WAV、OGG／OGA／Opus、AMR／纯音频3GP。后缀或MIME只用于发现候选，添加时通过MediaExtractor核对实际音轨和MediaCodecList解码能力；包含视频、专有文件或设备无法解码的编码不能添加。标签／封面／时长读取失败不直接等同于音频不支持。冷门编码、M4B等其它容器、压缩包和播放列表不在首版范围；格式和大目录性能仍需真实样本／设备验收，不以编译成功代替。

## 登录与平台状态

## 播放端既有契约

| 事件 | 音乐行为 |
| --- | --- |
| 正文准备／初次加载 | 等待正文第一次实际出声 |
| 正常句间、换章、短缓冲 | 连续播放，保持原速与进度 |
| 持续等待 | 约 8 秒后淡停，正文再出声时恢复 |
| 暂停、耳机／通知暂停 | 一并暂停，保留音乐位置 |
| 定时结束、全书结束、服务停止／销毁 | 一并停止并释放 |
| 切书／切引擎 | 保留全局选曲与音量，撤销旧宿主回调；首版不承诺跨服务无缝 |
| 调整正文倍速／音高 | 音乐始终原速，音量独立 |
| 来电、焦点、拔耳机 | 沿主听书服务现有策略，不建立第二套焦点或耳机控制 |
| 音乐网络／解码失败 | 有限刷新／跳过；连续三首或整队列失败后停音乐，正文继续 |

现役文字朗读或有声书服务分别持有同一控制器类型。BGM 不另开前台服务、通知或媒体会话，不参与 TTS 合成、缓存、阅读计时或正文进度。专用人声事件与逻辑暂停分开，不能用每段 `isPlaying=false` 立即关闭音乐。
