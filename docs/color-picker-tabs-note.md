## 2. 目标：三个通道入口，一份颜色，一套主题组件

**已锁定：** `色板 ┬ 色轮 ┬ 连续`。三个拧**当前这一笔色**（同一份 `currentColor`，含 alpha）。**AI Theme 不占颜色选择器 Tab**：阅读预设编辑器「配色」分成 `[手动 | AI]`；手动从文字滑到背景再滑到高亮；AI 页点一条即 `applyPaperLook`（底+字+强调+高亮）。RGB 与 HSV 仍收在「连续」里。色块网格可由「光谱」或具名纸感公式切换，不另开配色入口。

切 色板/色轮/连续 只换手势，不重置、不另开确认。透明度滑条、预览盒、hex **不占 Tab**，始终在三个通道 Tab 下面。

```
←  < 背景 >              [↺]     ← 标题可左右滑：文字 >  /  < 背景 >  /  < 高亮
┌ 色板 ┬ 色轮 ┬ 连续 ┐             ← 三等分；上次 Tab 记全局 pref
│                    │
│   动态区（按剩余高度封顶，不是写死 180dp）
│                    │
└────────────────────┘
不透明度  ────●──────── 100%     ← 预览用；正文/背景提交时 flatten
┌ 预览 64dp ─────────┐
│  天地玄黄  [宇宙洪荒。]  9.2:1 AAA  ← 正文 + 高亮片段；本地算
└────────────────────┘
[■] #FAF9F5
```

| 入口 | 用户可见 | 做什么 |
|---|---|---|
| **色板** / Grid | `NgColorPalette` 13×8；顶栏选公式（光谱 HSV 或种子 Oklch） | 快选当前槽位这一笔色 |
| **色轮** / Wheel | 外色相环 + **圆内方块**（横 S 纵 V；内部用 HCT tone 做轨道补偿） | 转一圈找色相；方块四角是白/黑/饱和/灰，不要三角 |
| **连续** / Continuous | 默认 **HSV**；可切 RGB | 直觉：色相→浓淡→明暗。RGB 是精确次选，不占根 Tab |

连续 Tab 不要拆成两个根 Tab。AI Theme 在配色入口，不要做成第四个颜色空间。无 Key / 离线时短句框隐藏或提示未配置，**公式随机纸感照常出**。

### 2.1 为什么是公共主题组件

Compose 已是阅读 NG / 主题设置的主路径。选择器应落在 `ui/design` 或现有 `NgColorPickerSheet.kt` 的升级，而不是阅读抽屉私有：

- `NgColorPickerSheet`（主题页 BottomSheet）和 `NgInlineColorPicker`（阅读抽屉内嵌）共用 **同一套三通道本体**。阅读配色的 AI 走独立页 `NgAiThemePane`，点选即整组写入。
- 外壳不同：sheet 有确认/顶栏文字模式；inline 有返回+重置、高度跟 `EditorPageHeight`。
- 控件：`NgSlider` `COMPACT`、`NgFlatActionRail`、`NgGlassSurface`、`NgFormField`。不引入第二套颜色库。
- `NgSoftGradientColorPresetSheet` 里单独画的 `NgColorPalette` 一并改为这个本体（或明确注明只保留色板变体）。

### 2.2 预览盒

始终同时出示文字和背景，否则透明度看不出来：

| 正在编辑 | 预览盒 |
|---|---|
| 文字 / 强调 / 高亮字 / 页眉字 | 样本文字用**当前色**（含 alpha）；底用本预设当前背景；后半句带高亮底 |
| 背景 | 底用**当前色**；样本文字用当前正文色；后半句带当前高亮底 |
| 预设高亮色 | 底用当前页背景；正文色不变；后半句高亮底用**当前色** |
| 主题种子 / 手动槽 | 大色块即可（没有阅读正文语境） |

拖任一通道 Tab、透明度、hex，预览立刻变（选择器内部态）。抬手后再 `onColorChanged`。AI 页点一条：整组写底+字+强调+高亮。

### 2.3 约束（已锁）

1. **对外 HSV/RGB/Hex，对内知觉亮度。** HSV 的 V 不是人眼明度（纯黄 V=1 与纯蓝 V=1 亮度差一个数量级）。滑条轨道、色轮步进、随机纸感、对比修复一律走已有 **HCT tone**（`com.materialkolor.hct.Hct`，仓里已有）。不要再手搓一套 Oklab 矩阵，除非 HCT tone 二分对不齐再补 Oklab L。用户仍看到熟悉的 HSV/RGB/Hex。
2. **即改即预览，提交才出选择器。** 拖动时只更新选择器内部 `TransformedState`；抬手或 1 帧防抖后才 `CommittedState` → `onColorChanged`。禁止每帧 `postEvent` 打阅读页。
3. **高度。** 动态区按剩余高度封顶（横屏优先保证预览+hex+alpha）；不要写死 180dp。
4. **Alpha。** 预览可半透明。**正文与背景提交前** `NgColorMath.blend` 固化为不透明 Hex（字形缓存/抗锯齿）。强调色/高亮允许保留 alpha。
5. **吸色另留。** 浮动窗从背景取色仍是全屏吸色。
6. **面板透明度**是抽屉 chrome（§5），不要和颜色 alpha 混。
7. **记 Tab。** 全局一份 pref；默认打开上次。连续子页默认 HSV。
8. **配色入口。** 预设编辑器「配色」两枚：`手动`（文字→背景→高亮，标题 `< … >` 可滑）和 `AI`（公式随机纸感 + 短句）。AI 不再出现在色板/色轮/连续旁边，也不再有「同步纸底」勾选——点一条即整组应用。

### 2.4 不吸收

- 从选色器 **写字距 / 改字重** 去抵夜间 irradiation（排版所有权不在颜色页；预览盒可视觉微调，不进 `ReadBookConfig`）。
- **APCA** 第二套对比库（WCAG 2.2 硬闸门保留；夜间加 §4.4 附加带即可）。
- 强调色用 **色相+180 互补**（易饱和；强调走深蓝 `#2B579A` 一类）。
- 墨水屏随机永远同一对 hex（用 D1/D3 策展，至多在灰阶里微扰）。
- 拖滑条时每帧做 8 次 Oklab 二分。
- 把 HSL lightness 当成 WCAG 相对亮度 L（评审伪代码混用了两种「L」）。

### 4.2 日 / 夜 / 墨水

列表随 **当前正在编的变体** 换（`isNightTheme` / e-ink），不要日夜混在一屏：

- **日间** 默认出示 D1 米白经典、D3 暖纸、D5 冷白（可再加 D2 高对比、D4 灰白）。

### 4.4 VDT 闸门（纸感准入 / 自定义预警）

长文清晰度主要由 **亮度对比** 驱动（M 通路），不是色相对比。具名纸感、AI 提案与通道 Tab 写出的色都宜过这张清单（VDT 文 §0/§3/§4）：

| 闸门 | 要 | 不要 |
|---|---|---|
| 极性 | 日间/e-ink：**深字浅底**（正极性，全龄速度/准确率更好） | 把反极性当白天默认；e-ink 深底浅字 |
| 对比 | 正文约 **7:1–12:1** 舒适带（WCAG AA 4.5 下限，长文宁取中段；屏比印刷略高） | 低于 4.5:1；日间拉满 21:1 |
| 非极值 | 深灰字 `#1F1F1F`–`#333` × 米白底 `#FAF9F5`–`#FFF`；夜底 `#1A1A1A` 级、夜字 `#C8C8C8` 级 | 正文 `#000`×`#FFF`（halation）；夜里纯白字+纯黑底 |
| 色相 | 颜色只做 **语义**（链接/状态/高亮块）；强调靠字重 | 饱和红/绿/亮蓝当正文（色差无法同焦） |
| 昼夜 | 日间偏冷白/米白；夜间偏暖、对比 **刻意低于** 日间（降总光通量） | 全天同一套冷白；夜里浅黄高亮块 |
| 小字 | 不够清时加 **字重**（在排版页，不在选色器） | 用加饱和度「补对比」 |
| 夜间附加 | 字重 < Medium 时叠色对比 **≥6:1**（生成带本就 8–10）；夜字 WCAG **L_fg ∈ [0.45, 0.70]**，Oklab/HCT L 上限约 0.82 防光斑 | 夜字发灰（L 过低）或发虚（近纯白 irradiation） |

VDT 文方案 A/B 与 ebook D1/N1 对齐，作为默认纸感：日间 `#FAF9F5`+`#333333`；夜间 `#1A1A1A`+`#C8C8C8`。屏幕 cd/m² 和室内 1:3:10 照明是系统/环境，**不进**这个选择器。

自定义拧出违规色时：预览盒可留并显示实测比（如 3.1:1）；纸感行取消勾选；**不**弹健康说教。生成路径（随机/AI）**禁止**把未过闸门的废案摆进列表：HCT tone 沿极性二分修字色（保色相/彩度），修到舒适带中段；修不够再丢这条，列表不空白。

未锁定：高亮规则是否共用夜用暗色块；跟随预设是否按槽位（只跟文字、底仍自定义）。强调色：成对写入时宜深蓝 `#2B579A` 类，已锁，不用互补色。

### 4.5 护栏：叠色后的 WCAG 对比（本地 ↻ 与 AI 共用）

可读性只认 **字/图标、底、alpha 叠完之后** 的亮度对比，不是生 hex，也不是模型形容词。App 主题页「使用色板生成颜色」是 Material 种子 → UI token，**不是**这条。这里只约束阅读 **底 / 字 /（高亮）**。

**叠色（先混合，再量）**

WCAG 对比只认最终画出来的不透明色。半透明字/底要先 source-over：

```
displayed = FG·α + BG·(1−α)     ← 已有 NgColorMath.blend
底自身半透明时：先把底叠到页图/下层，再把字叠到这张底上
```

然后用现成的 `NgColorMath.contrastRatio`（相对亮度 L，公式 `(L轻+0.05)/(L暗+0.05)`，sRGB 2.4 线性化）。**这是硬闸门，不换 APCA。** 已知暗区会偏乐观：所以夜间生成另加 L_fg 夹紧与 ≥6:1（字重偏低时）。不要再引入对比库。

**靶标（WCAG 2.2；长文再用 VDT 舒适带收窄）**

| 用途 | AA 下限 | AAA | 本应用生成时 |
|---|---|---|---|
| 正文（<18pt / 24px） | **4.5:1** | 7:1 | 日间 **8.5:1–13.5:1** 目标带（舒适约 7–12）；夜间 **7:1–11:1**（舒适约 8–10），仍 ≥4.5 |
| 大字（≥24px 或 ≥18.66px 粗体） | 3:1 | 4.5:1 | 页眉页脚/标题按这条 |
| 控件 / 图标 | 3:1 | 3:1 | 提示、分割线、图标 vs 其底 |

未过带：生成器换下一条或 **HCT tone 修字**（正极性压暗 / 反极性提亮，a/b 或 chroma 冻结）。用户手拧通道可以停在带外，预览标红比值即可。

本地 **↻** 收进 AI Theme：进 Tab / 点刷新都按公式再吐 3～5 条，不过模型。采样必须用 **HCT tone / 真实相对亮度**，不要用 HSL lightness 冒充 L。墨水屏用 D1/D3 策展，不要「随机」成固定一对。强调色走低饱和深蓝绿，禁止 hue+180。

### 4.6 AI Theme（第四入口：先数学，再短句）

进 Tab **立刻**用 §4.5 公式随机一组过闸门的纸感（日/夜/墨水按 §4.2），**不调模型**。下面一个短句框；有 Key 才按文案再生成相关主题。闸门始终是本地 §4.4 + §4.5，模型不能改闸门、不能自报对比过关。

```
┌ 色板 ┬ 色轮 ┬ 连续 ┬ AI ┐
│  纸感（公式随机，过闸门）              [↻]
│    米白经典  底 #FAF9F5  字 #333333
│    暖纸      …                         ← 点一条写入当前变体
│    …
│  ┌──────────────────────────────┐
│  │ 暖纸、夜里、少蓝          [生成] │  ← 短句；无 Key 则隐藏按钮
│  └──────────────────────────────┘
```

硬规则：

- 首屏与 ↻：**纯数学**，本地线程。日间：浅底深字、微暖纸浆色相、对比落入生成带。夜间：深灰底（非 0）、暖、L_fg 夹紧、对比低于日间。墨水：D1/D3 ± 微灰阶，正极性。每条过 `contrastRatio`；过不了就 HCT 修字再收入。无 Key 也能用完整 Tab。
- 短句生成：JSON `[{name, bg, fg, accent?}]`。模型挂了：**本地沿 HCT tone 修 fg** 到舒适带中段，**禁止把废案展示给用户**；修失败则保持当前公式组。不要靠「把比值塞回 prompt 再试」当主路径。
- **不**写字号/字体/字距、**不**新建 `configList` 阅读预设。
- 不把章节正文送给模型；最多书名/类型/封面主色（未锁定要不要带封面）。
- 点一条才写入；单槽宿主默认只取对应当前属性的那一通道，除非勾了同步纸底。
- 之后拧通道 Tab 即变为 Custom。
